사용자가 작성한 일기를 자연어 처리 기반 감정 분석 모델로 분석해 다음을 제공
-현재 감정 상태 파악
-장기 감정 변화 추적
-감정 패턴 시각화
-자기 감정 인식(Self-awareness) 지원

# 나. 프로젝트 개발 내용
## ● 연구개발 내용
본 연구개발에서는 자연어 처리(NLP) 기반의 개인 감정 분석 및 감정 변화 추적 일기 서비스를 개발하고자 하며, 이를 위해 사용자 감정 추출 모듈과 감정 변화 데이터 시각화 모듈을 개발하고자 함.

1. 프레임워크 선정 및 백엔드 아키텍처 설계 (app.py)
본 프로젝트의 웹 서버는 빠르고 가벼운 파이썬 기반의 웹 프레임워크인 FastAPI를 활용하여 구축함.

RESTful API 설계: 프론트엔드와 백엔드의 완전한 분리를 위해 REST API 아키텍처를 적용함. 사용자의 일기 데이터를 받아 AI 모델로 전달하는 /api/analyze (POST) 엔드포인트와, 누적된 감정 기록을 대시보드에 제공하는 /api/history (GET) 엔드포인트를 구현하여 데이터 통신을 최적화함.

템플릿 및 정적 파일 연동: Jinja2Templates를 활용해 HTML 화면을 동적으로 렌더링하며, CSS 및 JS와 같은 정적 파일(Static Files)을 효율적으로 서빙할 수 있도록 라우팅을 구성함.

CORS(교차 출처 리소스 공유) 처리: 개발 및 실서비스 환경에서의 원활한 API 호출을 위해 CORSMiddleware를 적용하여 외부 접근 허용 규칙을 안정적으로 제어함.

2. 사용자 중심의 메인 UI 구현 (index.html)
사용자가 매일 편안하게 일기를 작성할 수 있도록 직관적이고 심플한 사용자 경험(UX)을 제공하는 데 중점을 두었음.

비동기 통신 기반의 분석 요청: 텍스트 에어리어(Textarea)에 일기를 작성하고 분석 버튼을 누르면, 페이지 새로고침 없이 백엔드 서버와 비동기(Fetch API) 통신을 진행함.

로딩 상태 및 결과의 동적 렌더링: 인공지능 모델이 문맥을 분석하는 동안 사용자에게 '로딩 인디케이터'를 제공하여 시스템 진행 상황을 알림. 분석이 완료되면 도출된 '핵심 감정'과 그에 맞는 '맞춤형 위로/응원 문구'가 화면에 즉각적으로 표시되도록 구현하여 사용자와의 감정적 상호작용을 극대화함.

3. 데이터 시각화 및 감정 대시보드 UI (dashboard.html & graphs.py)
단발적인 일기 분석을 넘어, 사용자가 자신의 장기적인 감정 변화를 객관적으로 파악할 수 있도록 데이터 시각화 전용 대시보드 페이지를 별도로 구현함.

Chart.js를 활용한 통계 시각화: 오픈소스 시각화 라이브러리인 Chart.js를 도입하여 누적된 데이터베이스 정보를 직관적인 그래프로 표현했음. 전체 감정 분포를 한눈에 볼 수 있는 원형 차트와, 각 감정별 기록 횟수를 비교할 수 있는 막대 차트를 반응형 격자 레이아웃으로 나란히 배치했음.

기간별 감정 데이터 추출 모듈화: graphs.py 모듈을 설계하여 데이터베이스(emotions.json)에 저장된 전체 기록 중 '최근 7일(이번 주)'에 해당하는 데이터만 필터링하는 로직을 구현하였음. 이를 통해 요일별 감정의 흐름을 추적하고 캘린더나 주간 리포트 형태로 확장할 수 있는 데이터 처리 기반을 마련함.

## 감정 분석 모델 학습 및 성능 평가
1. 베이스 모델 선정 (Base Model Architecture)
본 프로젝트의 감정 분석을 위한 베이스 모델로는 한국어 자연어 처리에 우수한 성능을 보이는 monologg/koelectra-base-v3-discriminator 사전 학습 모델을 채택함. ELECTRA 아키텍처는 생성자가 만든 가짜 토큰을 판별하는 교체된 토큰 탐지 방식을 사용하여 한정된 자원 내에서도 효율적이고 빠르며, 한국어 문맥의 미세한 뉘앙스를 정확하게 파악할 수 있다는 장점이 있음.

2. 입력 데이터 전처리 및 토큰화 (Data Preprocessing & Tokenization)
사용자가 입력한 일기 텍스트는 ElectraTokenizer를 통해 모델이 연산할 수 있는 벡터 형태로 변환됨. 학습의 효율성과 일기 데이터의 일반적인 문장 길이를 고려하여 입력 데이터의 최대 길이는 128 토큰으로 제한함. 또한, 길이가 짧은 텍스트는 128 길이에 맞게 패딩 처리를 수행하여, 배치 단위의 텐서 연산이 병목 없이 안정적으로 이루어질 수 있도록 전처리 규격을 통일함.

3. 감정 분류를 위한 모델 파인튜닝 (Fine-Tuning for Sequence Classification)
사전 학습된 KoELECTRA 모델의 최상단에 문장 분류를 위한 선형 레이어를 추가한 ElectraForSequenceClassification 구조를 활용하여 파인튜닝을 진행함. 본 프로젝트에서 분류하고자 하는 최종 감정 카테고리의 수(7개)에 맞추어 모델의 출력 클래스 개수를 설정함. 이를 통해 모델은 입력된 일기 텍스트의 전체 문맥을 종합적으로 분석하고, 사전에 정의된 감정 클래스 중 가장 확률이 높은 단일 감정을 도출하도록 최적화됨.
